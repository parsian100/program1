# فندوق — بسته توسعه نسخه ۰٫۳ برای اندروید

**زبان:** Python | **رابط:** Kivy | **ابزار بسته‌بندی اندروید:** Buildozer

این نسخه نسبت به نمونه قبلی شامل ۵۰۰ مرحله در ۲۵ فصل، نقشه مراحل، ذخیره پیشرفت، سکه و راهنمای مرحله و تصویر اختصاصی کاراکتر فندوق است.

## ۱) پیش‌نیاز ویندوز ۱۰

Buildozer مستقیماً روی Windows اجرا نمی‌شود؛ طبق مستندات رسمی، در ویندوز باید از WSL2 و Ubuntu استفاده شود. پروژه را داخل فایل‌سیستم لینوکس بسازید، نه داخل `/mnt/c`، تا خطاهای ابزار ساخت و کندی کمتر شود.

در PowerShell با دسترسی Administrator:

```powershell
wsl --install
```

اگر دستور بالا در نسخه ویندوز شما پشتیبانی نشد، قابلیت Windows Subsystem for Linux و Virtual Machine Platform را از Windows Features فعال کنید، سیستم را Restart کنید و سپس توزیع Ubuntu را از Microsoft Store نصب کنید. برای WSL2 ممکن است به‌روزرسانی هسته WSL و فعال بودن مجازی‌سازی BIOS نیاز باشد.

بررسی وضعیت:

```powershell
wsl --status
wsl -l -v
```

توزیع Ubuntu باید نسخه 2 باشد. اگر VERSION برابر 1 بود:

```powershell
wsl --set-version Ubuntu 2
```

## ۲) انتقال پروژه به Ubuntu

فایل ZIP را در ویندوز از حالت فشرده خارج کنید. فرض کنیم در Downloads قرار گرفته است. در Ubuntu:

```bash
cp -r /mnt/c/Users/YOUR_WINDOWS_USER/Downloads/Fandoq_Release_Kit ~/Fandoq
cd ~/Fandoq
```

به جای `YOUR_WINDOWS_USER` نام پوشه کاربری ویندوز خود را قرار دهید.

## ۳) نصب ابزارهای ساخت

```bash
sudo apt update
sudo apt install -y git zip unzip openjdk-17-jdk python3-pip python3-venv \
  autoconf libtool pkg-config zlib1g-dev libncurses-dev libffi-dev \
  libssl-dev cmake build-essential
```

محیط مجازی:

```bash
python3 -m venv ~/fandoq-venv
source ~/fandoq-venv/bin/activate
python -m pip install --upgrade pip setuptools wheel
python -m pip install buildozer cython
```

## ۴) ساخت APK آزمایشی

از داخل پوشه پروژه:

```bash
buildozer -v android debug
```

اولین ساخت ممکن است طولانی باشد؛ Buildozer ابزارهای Android SDK و NDK را دانلود می‌کند. در صورت موفقیت فایل خروجی داخل `bin/` خواهد بود.

برای کپی APK به پوشه Downloads ویندوز:

```bash
mkdir -p /mnt/c/Users/YOUR_WINDOWS_USER/Downloads/FandoqBuild
cp bin/*.apk /mnt/c/Users/YOUR_WINDOWS_USER/Downloads/FandoqBuild/
```

## ۵) نکات مهم پیش از انتشار در کافه‌بازار

این بسته هنوز **نسخه آزمایشی توسعه** است و انتشار تجاری آن بدون تکمیل و آزمون توصیه نمی‌شود. واژه‌های نمونه باید توسط ویراستار فارسی بازبینی شوند؛ بعضی ترکیب‌ها یا صرف‌ها ممکن است در فرهنگ لغت پذیرفته‌شده شما نباشند. نسخه نهایی باید دست‌کم این موارد را داشته باشد:

- واژه‌نامه معتبر و بازبینی‌شده با سطح‌بندی دشواری و آزمون خودکار پاسخ‌ها
- طراحی و آزمون کامل راست‌به‌چپ و فونت فارسی روی گوشی‌های واقعی
- صفحه شروع، آموزش تعاملی، صدا و بازخورد بصری، تنظیمات و صفحه پشتیبانی
- ذخیره‌سازی امن و پایدار، بازیابی پس از بسته‌شدن و آزمون ارتقای نسخه
- سیاست حریم خصوصی و حداقل‌سازی مجوزها؛ در این نسخه مجوز اینترنت درخواست نشده است
- آیکن و اسکرین‌شات‌های واقعی از نسخه نهایی
- بررسی الزامات جاری کافه‌بازار برای نوع بسته، امضا و اطلاعات صفحه برنامه
- تست روی چند اندازه صفحه و نسخه Android، و رفع crash و مشکلات عملکردی

**کلید امضای برنامه را محرمانه نگه دارید و چند نسخه پشتیبان آفلاین امن داشته باشید.** از دست دادن کلید ممکن است انتشار به‌روزرسانی با همان شناسه برنامه را دشوار یا ناممکن کند. جزئیات فرمت و امضای مورد قبول بازار را در پنل رسمی توسعه‌دهندگان و مستندات روز آن بررسی کنید.

## ساخت خودکار APK با GitHub Actions (بدون نصب Ubuntu روی ویندوز)

۱. تمام محتویات داخل پوشه `Fandoq_Release_Kit` را در ریشه مخزن GitHub قرار دهید؛
   به‌طوری‌که `main.py` و `buildozer.spec` در ریشه مخزن باشند و پوشه
   `.github/workflows/android.yml` نیز حفظ شود.
۲. تغییرات را روی شاخه `main` ذخیره کنید.
۳. در GitHub وارد تب **Actions** شوید و اجرای **Build Fandoq Android APK** را باز کنید.
۴. پس از پایان موفق، در پایین صفحه اجرای Workflow، از بخش **Artifacts** فایل
   `Fandoq-Android-debug` را دانلود کنید. فایل ZIP دانلودی شامل APK است.

این Workflow یک APK آزمایشی (debug) تولید می‌کند، نه نسخه نهایی امضاشده برای انتشار.
ساخت واقعی به اجرای موفق GitHub Actions و آزمون روی گوشی نیاز دارد.
